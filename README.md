# 🧹 Windows Ultimate System Cleaner

Bilgisayarınızın zamanla yavaşlamasına sebep olan gereksiz geçici dosyaları, önbellekleri ve logları tek tıkla temizleyerek sisteminizi rahatlatan güçlü bir Batch (`.bat`) betiği. 

## 🚀 Özellikler
Bu script çalıştırıldığında sistemde şu işlemleri gerçekleştirir:
- **Geçici Dosyalar (Temp & Prefetch):** Windows ve kullanıcı dizinlerindeki gereksiz dosyaları siler.
- **DNS Önbelleği:** İnternet bağlantı sorunlarını çözmek için DNS geçmişini temizler.
- **Windows Update & Olay Günlükleri:** Eski güncelleme kalıntılarını ve gereksiz hata raporlarını (WER) siler.
- **Gereksiz Hizmetler:** Arka planda sistemi yoran `wsearch`, `DiagTrack` ve `sysmain` hizmetlerini durdurur.
- **Disk Temizleme & Birleştirme:** Windows'un yerleşik araçlarını (Cleanmgr & Defrag) tetikleyerek diski optimize eder.

---

## 🛠️ Nasıl Kullanılır?
Script, Windows sistem klasörlerine müdahale ettiği için **Yönetici İzni** ile çalıştırılmalıdır.

## 🚀 Kullanım
1. Depodaki `.txt` dosyasını bilgisayarınıza indirin.
2. Dosyayı `.bat` dosyasına çevirin
3. Dosyaya **Sağ Tıklayın** ve **"Yönetici Olarak Çalıştır"** seçeneğine tıklayın.
4. Arkanıza yaslanın ve scriptin yeşil ekranda adım adım sistemi temizlemesini izleyin.
5. İşlem bitince herhangi bir tuşa basarak ekranı kapatabilirsiniz.
